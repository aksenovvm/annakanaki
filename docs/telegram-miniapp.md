# Telegram Mini App (этап 6)

Mini App — это наш сайт записи, который открывается **прямо внутри Telegram**.
Он ходит в тот же API и ту же базу, что и сайт:

```text
Сайт (localhost:3000) ─────┐
                           ↓
                 API (localhost:4000) → PostgreSQL (Supabase)
                           ↑
Mini App (localhost:5173) ─┘
```

Как Telegram сообщает, **кто** записывается: при открытии он передаёт приложению строку `initData`
с данными пользователя и подписью, сделанной ключом вашего бота. Сервер проверяет подпись
(`apps/api/src/telegram/initData.ts`) — подделать её без токена бота нельзя. Поэтому в Mini App
не нужны ни регистрация, ни пароль, ни даже телефон.

---

## Шаг 1. Создаём бота и получаем токен

1. Откройте в Telegram **@BotFather** (с синей галочкой).
2. Отправьте `/newbot`.
3. Имя бота — например, `Kanaki Barbershop`.
4. Username — латиницей и обязательно с `bot` на конце, например `kanaki_barbershop_bot`.
5. BotFather пришлёт **токен** вида `1234567890:AAH...`.

Откройте **`apps/api/.env`** (именно `.env`, не `.env.example`) и добавьте строку — токен в кавычках:

```env
TELEGRAM_BOT_TOKEN="1234567890:AAH..."
```

Сохраните файл (**Cmd + S**). Если `npm run dev` уже запущен — **перезапустите** его (Ctrl + C, затем снова
`npm run dev`): сервер читает `.env` только при старте.

⚠️ Токен — это пароль от бота. Не отправляйте его в чат, не вставляйте в код Mini App или сайта.
Если токен утёк — в @BotFather: `/mybots` → ваш бот → **API Token** → **Revoke current token**.

## Шаг 2. Проверяем в обычном браузере

В браузере нет Telegram, а значит нет и `initData`. Для разработки есть скрипт, который
подписывает тестовую строку **вашим** токеном — так же, как это делает Telegram:

```bash
npm run tg:dev-init-data
```

Скрипт сам создаст файл **`apps/miniapp/.env.local`** с тестовым входом. Запустите (если ещё не запущено):

```bash
npm run dev
```

Откройте **http://localhost:5173** — это Mini App. Вы будете «Тестовым Клиентом».
Если страница была открыта раньше — просто обновите её.
Строка действует сутки — потом запустите скрипт снова.

## Шаг 3. Открываем внутри Telegram

Telegram открывает Mini App только по адресу **https://**. Наш `localhost` для него недоступен,
поэтому нужен **туннель** — временный публичный адрес, который ведёт на ваш компьютер.

1. Установите cloudflared (один раз):
   ```bash
   brew install cloudflared
   ```
2. Запустите сайт, API и Mini App: `npm run dev` (в одном окне терминала).
3. В **другом** окне терминала (Terminal → New Terminal):
   ```bash
   cloudflared tunnel --url http://localhost:5173
   ```
   Через несколько секунд появится адрес вида **`https://something-random.trycloudflare.com`**. Скопируйте его.
   Окно не закрывайте — пока оно открыто, туннель работает.
4. В **@BotFather**: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button**.
   Отправьте скопированный адрес, затем название кнопки — например, `Записаться`.
5. Откройте вашего бота в Telegram (на телефоне или в Telegram Desktop) и нажмите кнопку **«Записаться»**
   слева от поля ввода сообщения.

Запросы к API идут через тот же туннель: Vite пересылает `/api/...` на `localhost:4000`.

> ⚠️ Бесплатный адрес cloudflared **меняется при каждом запуске**. Запустили туннель заново —
> обновите адрес в @BotFather (шаг 4). Постоянный адрес появится на этапе 11 (деплой на Vercel).

## Что умеет Mini App

- **Записаться:** услуга → барбер (или «Любой свободный») → дата и время → подтверждение.
  Имя подставляется из Telegram, телефон — по желанию.
- **Мои записи:** предстоящие и история за 60 дней.
- **Перенос и отмена** — в карточке записи, не позднее чем за 30 минут до начала.
- Если время успели занять — «Это время только что заняли» и возврат к выбору времени.
- Цвета берутся из темы Telegram (светлой или тёмной), кнопки «Далее»/«Записаться» и «Назад» —
  нативные кнопки Telegram.

Запись из Mini App сохраняется с `source = telegram`, клиент привязан к Telegram-аккаунту
(`clients.telegram_id`). В Supabase её видно в `bookings_readable` (колонка `source`).

## Если что-то не так

| Что видите | Что делать |
|---|---|
| «Откройте через Telegram» в браузере | Нет тестового входа — выполните `npm run tg:dev-init-data` и обновите страницу |
| «Не удалось проверить вход через Telegram» | Токен в `apps/api/.env` не от того бота, что открывает Mini App, или строка из шага 2 сделана другим токеном |
| «Сессия Telegram устарела» | Закройте и снова откройте Mini App (в браузере — снова `npm run tg:dev-init-data`) |
| «Вход через Telegram не настроен» | В `apps/api/.env` нет `TELEGRAM_BOT_TOKEN`; после добавления перезапустите `npm run dev` |
| В Telegram белый экран или «Blocked request» | Туннель не запущен или адрес в @BotFather устарел — шаги 3–4 |
| `cloudflared: command not found` | `brew install cloudflared` (нужен Homebrew) |
